# Customer Shopping Behavior Analysis 📊

## 1. Project Overview

This project focuses on analyzing customer shopping behavior using transactional data to identify purchasing patterns, customer preferences, spending trends, and subscription behavior.

The objective is to transform raw customer shopping data into meaningful business insights using Python, MySQL, and Power BI.

The project follows an end-to-end data analytics workflow, including data loading, exploratory data analysis (EDA), data cleaning, SQL-based analysis, dashboard development, and business reporting.

The analysis aims to help businesses understand customer behavior, improve customer retention, optimize discount strategies, and make data-driven decisions.

## 2. Dataset

The project uses a Customer Shopping Behavior dataset containing information about customer demographics, purchase transactions, product categories, and shopping preferences.

**Dataset Details:**

- Total Records: 3,900
- Total Columns: 18
- Missing Values: 37 (Review Rating column)
- File Format: CSV

**Key Features:**

| Category | Attributes |
|---|---|
| Customer Demographics | Age, Gender, Location, Subscription Status |
| Purchase Details | Item Purchased, Category, Purchase Amount, Season |
| Product Information | Size, Color |
| Shopping Behavior | Discount Applied, Promo Code Used, Previous Purchases |
| Customer Experience | Review Rating, Shipping Type |
| Purchase Patterns | Frequency of Purchases, Payment Method |

## 4. Project Workflow

### Step 1: Data Loading & Initial Exploration (Python)

- Imported the dataset into Python using Pandas.
- Examined dataset dimensions and structure.
- Used `df.info()` to understand data types and column information.
- Used `df.describe()` to generate statistical summaries.

### Step 2: Exploratory Data Analysis (EDA)

- Analyzed customer demographics and purchasing patterns.
- Examined product categories and customer preferences.
- Explored purchase amounts and spending behavior.
- Investigated customer subscription patterns.
- Identified trends and relationships within the dataset.

### Step 3: Data Cleaning & Preprocessing

Performed data cleaning using Python and Pandas.

Key activities included:

- Handled 37 missing values in the `review_rating` column using the median rating of each product category.
- Standardized column names into snake_case format.
- Created an `age_group` column by categorizing customer ages.
- Created a `purchase_frequency_days` column.
- Checked redundancy between `discount_applied` and `promo_code_used`.
- Removed the redundant `promo_code_used` column.
- Prepared the cleaned dataset for database analysis.

### Step 4: Database Integration (MySQL)

- Connected Python to MySQL.
- Transferred the cleaned DataFrame into the MySQL database.
- Stored the processed dataset for structured querying and analysis.
- Used MySQL to perform business-focused data analysis.

### Step 5: SQL Analysis (MySQL)

Executed SQL queries to answer important business questions and extract actionable insights.

**Key Business Questions:**

1. **Revenue by Gender:** Compared total revenue generated by male and female customers.

2. **High-Spending Discount Users:** Identified customers who used discounts but still spent above the average purchase amount.

3. **Top 5 Products by Rating:** Identified products with the highest average customer review ratings.

4. **Shipping Type Comparison:** Compared average purchase amounts between Standard and Express shipping.

5. **Subscribers vs. Non-Subscribers:** Analyzed customer count, average spending, and total revenue based on subscription status.

6. **Discount-Dependent Products:** Identified the five products with the highest percentage of discounted purchases.

7. **Customer Segmentation:** Classified customers into New, Returning, and Loyal segments based on purchase history.

8. **Top 3 Products per Category:** Identified the most purchased products within each product category.

9. **Repeat Buyers & Subscriptions:** Analyzed subscription behavior among customers with more than five purchases.

10. **Revenue by Age Group:** Evaluated revenue contribution across different customer age groups.

## 6. Key Results & Business Insights

The analysis generated several important findings.

### Key Metrics

| Metric | Result |
|---|---:|
| Total Customers | 3,900 |
| Average Purchase Amount | $59.76 |
| Average Review Rating | 3.75 |
| Total Revenue | $233,081 |
| Subscribers | 1,053 |
| Non-Subscribers | 2,847 |

### Important Findings

- **Customer Segmentation:** 3,116 customers were classified as Loyal, 701 as Returning, and 83 as New.
- **Subscription Behavior:** Non-subscribers generated higher total revenue because of their larger customer base.
- **Shipping Analysis:** Express shipping customers had a higher average purchase amount ($60.48) compared to Standard shipping ($58.46).
- **Product Ratings:** Gloves, Sandals, Boots, Hat, and Skirt were among the five highest-rated products.
- **Discount Analysis:** Hats had the highest discounted purchase percentage at 50%.
- **Age Group Analysis:** Young Adults contributed the highest revenue ($62,143).

### Business Recommendations

Based on the analysis, the following recommendations were identified:

1. **Boost Subscriptions:** Promote exclusive benefits and incentives to encourage customers to subscribe.
2. **Customer Loyalty Programs:** Reward repeat buyers and strengthen customer retention.
3. **Review Discount Policy:** Balance promotional discounts with profitability and margin control.
4. **Product Positioning:** Highlight top-rated and best-selling products in marketing campaigns.
5. **Targeted Marketing:** Focus marketing efforts on high-revenue age groups and customers using Express shipping.
